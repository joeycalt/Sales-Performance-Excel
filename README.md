# Retail Sales Performance Analysis | Excel

## Project Overview

This project explores retail sales transaction data using Microsoft Excel to evaluate sales performance across product categories, geographic regions, and individual products.

The analysis demonstrates an Excel-based workflow, from organizing and preparing data to applying formulas, building pivot tables, and structuring results for reporting.

The goal is to better understand sales activity, identify performance differences, and support data-driven business decisions.

## Tools & Skills

**Tools:** Microsoft Excel

**Skills demonstrated:**
- Data organization and preparation
- Excel formulas and conditional aggregation
- Pivot table analysis
- Revenue and sales performance analysis
- Category and regional comparisons
- Data reporting and dashboard preparation

## Dataset Overview

The workbook contains **193 sales transaction records** with information including:

- Transaction ID and date
- Product category and product name
- Units sold and unit price
- Total revenue
- Geographic region
- Payment method
- Product performance tier

The dataset covers multiple retail categories, including Beauty Products, Books, Clothing, Electronics, Home Appliances, and Sports.

## Project Workflow

### 1. Data Preparation

The workbook separates the original sales dataset from a cleaned version to support further analysis.

The `Raw_Data` worksheet contains the source transaction records, while `Clean_Data` provides a structured dataset with consistent column organization for analysis.

### 2. Excel Formula Analysis

The `Excel_Analysis` worksheet uses Excel functions to calculate performance metrics.

Key functions include:

- **AVERAGEIF:** Calculates average transaction revenue by product category.
- **COUNTIF:** Counts transactions within each category.
- **SUMIF:** Calculates total units sold by category.

These formulas help compare category-level sales activity and provide additional metrics beyond the original transaction data.

### 3. Pivot Table Analysis

The `Pivot_Table` worksheet organizes sales information into summarized views.

The analysis supports comparisons of product categories and sales volumes, helping identify differences in purchasing activity.

### 4. Dashboard & Reporting

The workbook also includes a `Dashboard` worksheet as part of its reporting structure.

The project brings together transactional data, calculated metrics, and summarized analysis to support business performance reporting.
